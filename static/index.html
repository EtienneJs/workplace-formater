Formateo a HTML

Texto o CSV → HTML con reglas locales y Ollama

Qué es Arranque Texto CSV Tabla Visor de celda Cambios JSON Configuración Atajos

Qué es

Formatea texto plano o celdas de un CSV a HTML con reglas en Markdown y un modelo local de Ollama. Todo corre en tu máquina: no se envía nada a internet.

Reglas
Archivos .md en rules/. Son las instrucciones que recibe el modelo.
Modelo
El LLM de Ollama que genera el HTML. Se elige en Configuración.
Sesión
El CSV, las celdas formateadas y las reglas de columna se guardan solos en datos/sesion.json.

Arranque

  1. Instalá Ollama y bajá un modelo, por ejemplo ollama pull qwen2.5:7b.
  2. Doble clic en iniciar.bat (o el acceso directo).
  3. Abrí http://localhost:8000. Para apagar, cerrá la ventana negra.

La primera vez crea el entorno virtual e instala dependencias. Después solo arranca el servidor.

Cargás un archivo, formateás celdas por columna y exportás CSV o JSON.

Arrastrá un CSV o hacé clic. Detecta coma, punto y coma o tabulación.
Regla general

Formatear tabla

Formatear celdas
Solo aparece en modo Seleccionar. Formatea las marcadas, aunque ya tengan HTML.
Detener
Corta el lote en curso. Lo ya hecho queda guardado.
Código HTML
Alterna la vista de las celdas entre HTML renderizado y código coloreado.
Restaurar
Borra el HTML de todas las celdas y vuelve al texto original.
CSV / JSON
Descargan el archivo con el trabajo actual.
Vista previa / Referencia

Progreso guardado

Interruptor de columna
Incluye o excluye la columna del JSON. Las excluidas se ven atenuadas.
Engranaje
Configura el nombre de la clave JSON y si la columna se exporta.
Regla de columna
Vacío = regla general. Si elegís una, esa columna usa esa regla.
Formatear (columna)
Formatea solo las celdas pendientes de esa columna.
Formatear / Original (celda)
Aparecen al pasar el mouse. Formatean o restauran esa celda.
Etiqueta de regla
Indica con qué regla se formateó.
⚠ +N −N

Seleccionar
Modo para marcar celdas, filas o columnas. Clic, arrastre o Shift + clic. Esc sale.
Ocultar excluidas
Esconde las filas que no van al JSON.
Clic en una celda
Abre el visor (si no estás en modo Seleccionar).

Visor de celda

Modal al hacer clic en una celda. Las flechas ← → ↑ ↓ cambian de celda sin cerrarlo.

Vista
HTML renderizado.
Código HTML
Código con números de línea y colores.
Original
El texto del CSV antes de formatear.
Cambios
Diff palabra por palabra respecto del original (ver siguiente sección).
Pedir cambio
Instrucción al modelo sobre el HTML o el original (según la pestaña). Mejor un pedido a la vez.
Editar
Edición manual del texto o del HTML. Ctrl + Enter guarda; Esc cancela.
Copiar
Copia el contenido de la pestaña activa.
Volver al original
Borra el HTML de esa celda.
Formatear / Volver a formatear
Corre el modelo otra vez con la regla de su columna.

Pestaña Cambios

Compara el HTML con el original, ignorando etiquetas, mayúsculas, signos y la numeración de listas.

Bloque de cambio
Cada diferencia es un bloque estilo git: línea − (quitado) y + (agregado).
✓ Aceptar
Deja el cambio del modelo. Saca el aviso ⚠ cuando no quedan pendientes.
✕ Rechazar
Vuelve el texto original en ese tramo del HTML, sin llamar al modelo.
Aceptar / Rechazar todos
Aplica la acción a todos los cambios pendientes.
Deshacer
En un cambio ya aceptado, lo vuelve a dejar pendiente.
Texto completo
Desplegable con todo el texto y las diferencias en línea.

Si un rechazo no se puede aplicar solo (HTML muy enredado), la app lo avisa: corregilo con «Editar HTML».

JSON y referencia

Vista previa

Referencia
Pegá un JSON de ejemplo. Sus claves aparecen como sugerencias al configurar columnas con el engranaje.
Guardar / Eliminar
Las referencias viven en la carpeta referencias/.
Ordenar JSON
Formatea el texto de la referencia.
